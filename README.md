# SF6 差し合いノート

『ストリートファイター6』の地上戦で、差し・置き・差し返しをどう使い分けるかを、上級者の方の話をもとにまとめた非公式ファンメイド記事です。

- 発生・持続・硬直と差し返しの関係（フレーム図）
- 3つの手がループする読み合いの全体像
- STEP 01〜03 の考え方とコツ
- 差し合いカード3枚（動画）

`index.html` 1ファイルで動く静的サイトです。ビルド不要。カード動画は `video/`（WebM と、Safari 向けの MP4）、動画を読み込む前に出す静止画は `img/` にあります。

「前提」と「相手の知識」の節は書き手が補足したものです。

『ストリートファイター6』およびキャラクターは株式会社カプコンの著作物・商標です。本ページはカプコンとは関係ありません。
